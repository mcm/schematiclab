# Camo shape packs: notices

The shape packs in this directory are generated by `pnpm gen:camo-shapes` (`scripts/generate-camo-shapes.mts`) from hand ports of each mod's model code. Each pack's `source` field records the repository, commit, mod version and license it was generated from. Update the commits below whenever a pack is regenerated.
